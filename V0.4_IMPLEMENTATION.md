# TÀNG THƯ OPDS — v0.4 implementation note

## Scope

v0.4 implements the first real storage layer and scanner without adding unnecessary infrastructure.

Implemented:

- Google Drive API v3 adapter using the standard library only.
- Public/shared-folder validation.
- Retrieval of the real Drive folder name.
- Recursive folder scan.
- Persistent JSON catalog.
- Parent-child relationships preserved.
- Drive-provided MD5 checksum retained when available.
- Branch registration with independent display name.
- Duplicate root-folder detection.
- Branch rename/hide/restore.
- `online`, `hidden`, and `unavailable` states.
- Manual refresh.
- Automatic refresh every hour.
- Public Web catalog without download routes.
- Recursive Web folder navigation.
- OPDS Branch -> folder -> file navigation.
- Admin HTTP Basic Authentication.
- Tests for URL parsing and branch-priority behavior.

Not implemented yet:

- OPDS acquisition streaming.
- Search.
- OAuth/private Drive.
- Production rate limiting and abuse protection.
- EPUB/OPF metadata.

## Configuration

Required environment variables:

```text
TANGTHU_GOOGLE_API_KEY=...
TANGTHU_ADMIN_PASSWORD=...
```

Optional:

```text
TANGTHU_ADMIN_USER=admin
TANGTHU_DATA_FILE=data/catalog.json
```

The Google API key must never be committed to the repository.

## Google Drive access model

The adapter uses the Google Drive API with an API key for folders that are publicly accessible by link. Google documents this pattern for public folders. Shared-drive requests include the shared-drive parameters.
